# TechFlow Solutions – Sistema de Gerenciamento de Tarefas

## Objetivo
Desenvolver um sistema básico de gerenciamento de tarefas, permitindo criar,
visualizar, atualizar e remover tarefas, aplicando conceitos de Engenharia de
Software e metodologias ágeis.

## Escopo Inicial
- Cadastro de tarefas
- Listagem de tarefas
- Atualização de tarefas
- Remoção de tarefas

## Metodologia Adotada
Foi utilizada a metodologia ágil Kanban, com organização das atividades em um
quadro no GitHub Projects, dividido em To Do, In Progress e Done, permitindo
visualização contínua do fluxo de trabalho.

## Tecnologias Utilizadas
- Python
- Git e GitHub
- Pytest (testes automatizados)
- GitHub Actions (CI)
